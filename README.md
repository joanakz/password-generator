# Password Generator

A beginner-friendly Python command-line tool that generates passwords using cryptographically secure random character selection.

## Features

- Custom password length
- Minimum password length of 12 characters
- Cryptographically secure random generation using the secrets module
- Uses uppercase and lowercase letters, digits, and special characters
- Input validation to handle invalid entries
- Clear error messages

## How to Use

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   ```bash
   python3 password_generator.py
   ```

5. Enter your desired password length (at least 12 characters).
6. The generated password will be displayed.

## Example

Enter password length: 16

Your password is: K7@m2!pL9#xQ4&zB

The example is illustrative. Each generated password uses randomly selected characters.
